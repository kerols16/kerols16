Android & Flutter developer with a B.Sc. in Computer Science from Thebes Academy (graduated June 2026). I build offline-first mobile apps with clean, maintainable architecture, and I like probing an API before I trust it.

Most recently I built **Marketly**, a native Android e-commerce app with Jetpack Compose, Clean Architecture, MVVM, Hilt, Room and Paging 3. Room is the single source of truth, the API has no keyword search so search runs locally as one paged query, cart and wishlist update optimistically with rollback, and the project has 138 unit tests and GitHub Actions CI. Before that I architected **Tamrinak**, an offline-first workout tracker with Hive and Firebase sync, and built **EduManage** as my graduation project, a multi-role school management system with 5 user roles and 50+ REST API endpoints. I also completed a DEPI internship, NTI Flutter/Firebase training, and the Sprints × Microsoft summer camp.
